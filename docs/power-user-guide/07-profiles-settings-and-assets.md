# Profiles, Settings, and Assets

Profiles control data ownership. Settings and assets customize the working environment.

## Profiles

A profile owns:

- Commitments.
- Behaviours.
- Frequencies.
- Activities.
- Notes.
- Tags.
- To-dos.
- Dashboard cards.
- Digital assets.

Use separate profiles when the data should not mix.

## Manage Profiles

1. Open Profiles.
2. Review the list of profiles.
3. Create a profile when you need a separate workspace.
4. Delete only profiles that are no longer needed.

Deleting or switching profiles can change every list and dashboard tile because the active profile scopes all data.

## Active Profile Checks

Check the active profile when:

- A grid is unexpectedly empty.
- Dashboard metrics look wrong.
- Live updates are not appearing.
- Notes or tags seem missing.
- You just logged in after using another profile.

## My Profile

Use My Profile to maintain profile display details.

Typical fields:

- Name.
- Avatar image URL.

If the page includes a digital asset URL input, upload or select the asset first, then save the profile.

## Digital Assets

Digital assets are profile-scoped files such as images used by profile avatars, notes, or dashboard cards.

Asset workflow:

1. Open the editor that needs an asset.
2. Use the digital asset URL input.
3. Upload or select the asset.
4. Confirm the URL appears.
5. Save the parent record.

If an asset does not render, confirm that the active profile owns it.

## Settings

Settings are for application preferences. The current settings surface includes language selection.

Use Settings to:

- Confirm English or French language selection.
- Validate that labels still make sense after changing language.

## Profile Switch and Live Dashboard

Live dashboard updates are profile-scoped. After switching profiles:

1. Return to Dashboard.
2. Confirm the active profile name.
3. Refresh the dashboard if values look stale.
4. Verify that live tiles now reflect the new profile's data.
