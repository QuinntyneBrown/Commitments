# To-Dos, Notes, and Tags

To-dos and notes complement commitments. Use commitments for recurring expectations, to-dos for discrete work, and notes for context.

## To-Dos

To-dos are one-off tasks or reminders. They can be created, edited, completed, and deleted.

Use to-dos for:

- "Call dentist."
- "Prepare weekly review."
- "Fix dashboard card layout."
- "Upload profile avatar."

Do not use to-dos for recurring behaviours. Use commitments and activities for that.

## To-Do Workflow

1. Open To Do's.
2. Add a to-do.
3. Give it a clear title.
4. Save.
5. Mark it complete when finished.
6. Delete it only when you no longer need the record.

The Outstanding To Dos dashboard tile reflects open task pressure. Completing a to-do should reduce outstanding count on the next tile update or refresh.

## To-Do Power Habits

- Keep task titles action-oriented.
- Break large tasks into one next action.
- Review open to-dos before changing daily commitments.
- Use dashboard live mode to keep open to-dos visible.

## Notes

Notes are rich-text records for plans, decisions, reflections, and supporting context.

Use notes for:

- Weekly review summaries.
- Reasons for changing a commitment.
- Observations from dashboard trends.
- Experiment logs.
- Retrospectives.

## Create or Edit a Note

1. Open Notes.
2. Create a note or open an existing note.
3. Enter a title.
4. Write the body in the rich text editor.
5. Add tags.
6. Save.

The editor stores rich text content, so use headings, lists, and short sections when the note will be reused during review.

## Tags

Tags make notes retrievable by theme.

Useful tag examples:

- weekly-review
- dashboard
- health
- work
- experiment
- retrospective
- decision

Use a small set of stable tags. Too many near-duplicate tags make review harder.

## Notes by Tag

Use Notes by Tag when you want to read every note tied to a theme. This is useful before changing commitments or during a weekly review.

Workflow:

1. Choose or create a tag.
2. Tag related notes consistently.
3. Open the notes-by-tag view for that tag.
4. Review the full context before acting.

## Weekly Review Workflow

1. Open Dashboard Review mode.
2. Scrub the previous seven days.
3. Open Notes and create a weekly review note.
4. Tag it `weekly-review`.
5. Capture metric changes, missed activities, and decisions.
6. Convert any one-off follow-up into a to-do.
7. Convert any recurring expectation into a commitment.
